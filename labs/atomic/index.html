AL-2 構成で使う命令
命令動作不可分か
LI rd, imm · MOV rd, rs · ADDI · SUBIレジスタの計算（r0 は常に 0）—
LW rd, counterメモリから読む（counter は番地 0x00 の記号）単独の読み出しは不可分
SW rs, counterメモリへ書く単独の書き込みは不可分
INCM counterメモリを +1。内部で「読み出し」「書き込み」の2 μop に分かれる（独自拡張 Xmrmw）いいえ
LOCK INCM counterバスをロックしたまま読み出しから書き込みまで行うはい
AMOADD rd, rt, counterrd ← 旧値、メモリ ← 旧値 + rt（fetch-and-add）はい
XCHG rd, lockrd とメモリを入れ替える（test-and-set に使う）はい
CAS rd, rt, counterメモリ = rd なら rt を書く。どちらの場合も rd ← メモリの旧値はい
LL rd, counter読み出して番地を予約する—
SC rd, rt, counter予約が残っていれば rt を書いて rd ← 1、消えていれば rd ← 0はい
J label · BEQZ / BNEZ rs, label · BNE rs, rt, label無条件ジャンプ / 0 なら / 0 でなければ / 等しくなければ—
HALT · NOP停止、何もしない—
.region cs ～ .endregionクリティカルセクションの範囲を示す印（命令ではない）。2コアが同時に入ると警告—

メモリは counter（0x00）と lock（0x04）の2語。両方のコアが同じプログラムを実行し、レジスタはコアごとに16本（ここでは r0〜r7 を表示）。1ステップで1命令（INCM は1 μop）を実行します。命令の正式な定義は命令セット一覧へ。
