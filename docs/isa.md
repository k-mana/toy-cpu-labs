# TOY 命令セット仕様

版: 1.0

TOY は、コンピュータアーキテクチャを学ぶために作った 32 ビットのロード/ストア型命令セットです。実在の RISC-V や MIPS に近い形をしていますが、教材として読みやすいように単純にしてあります。

この文書は「何が正しい動作か」の定義です。シミュレータ (`core/`) はこの文書に従って作られており、食い違いがあればこの文書を正とします。命令の一覧表は[命令セット一覧](../reference/)でも見られます (そちらはコードから自動で作られます)。

## 1. 構成

命令セットは**拡張**の組み合わせで決まります。

| 拡張 | 名前 | 中身 | オペコード範囲 |
|---|---|---|---|
| **I** | 基本整数命令 | 演算・ロード/ストア・分岐・ジャンプ・停止 | `0x01`〜`0x3F` |
| **M** | 乗算・除算 | MUL, DIV, REM など | `0x40`〜`0x4F` |
| **A** | アトミック | LL/SC, CAS, XCHG, AMOADD | `0x50`〜`0x5F` |
| **X…** | 独自拡張 | 教材ごとに足す命令 (例: `Xmrmw`) | `0xC0`〜`0xFF` |

`0x60`〜`0xBF` は将来の標準拡張のために予約します。オペコード `0x00` は常に不正な命令です (ゼロで埋まったメモリを実行しても何かが起きないように)。

組み合わせは拡張名を並べて `TOY-IMA` のように呼びます。I は必ず含めます。

## 2. 状態

### 2.1 レジスタ

| 名前 | 用途 |
|---|---|
| `r0` | 常に 0。書き込みは捨てられる |
| `r1`〜`r14` | 汎用 |
| `r15` | 汎用。`CALL` が戻り先を入れる (慣習として「リンクレジスタ」) |

レジスタはすべて 32 ビットの 2 の補数で、演算はすべて 2^32 で割った余り (桁あふれは捨てる) です。演算で例外は起きません。

### 2.2 プログラムカウンタ (PC)

PC は**命令の番号** (0, 1, 2, …) です。命令メモリとデータメモリは別々で (ハーバード構成)、命令はデータメモリからは読めず、書き換えもできません。リセット時の PC は 0 です。

> 実機の多くは PC をバイト番地で数え、命令は 4 ずつ進みます。TOY では表示を読みやすくするために番号で数えます。

### 2.3 データメモリ

- 番地は**バイト単位**で、0 から `メモリの大きさ − 1` まで。大きさは構成ごとに決まります (既定 64 KiB)。
- 複数バイトの値は**リトルエンディアン** (下位バイトが小さい番地)。
- ワード (4 バイト) の読み書きは、番地が 4 の倍数でなければなりません。
- 範囲外・境界違反のアクセスは[例外](#6-例外)になります。

### 2.4 マルチコア

複数のコアは同じプログラムとデータメモリを共有し、レジスタ・PC・予約 (§4.3) はコアごとに持ちます。1 ステップで 1 つのコアが 1 命令 (μop 命令なら 1 μop) を実行します。どのコアをいつ動かすかは構成 (スケジューラ) が決めます。

## 3. 命令形式

すべての命令は 32 ビットです。上位 8 ビットがオペコードで、残りの使い方は形式で決まります。

```
 31      24 23  20 19  16 15  12 11                    0
┌────────┬──────┬──────┬──────┬───────────────────────┐
│ opcode │  rd  │  rs  │  rt  │          0            │  R
│ opcode │  rd  │  rs  │       imm16                  │  I
│ opcode │  rt  │  rs  │       imm16                  │  S  ストア
│ opcode │  rs  │  rt  │       off16                  │  B  分岐
│ opcode │  rd  │          target20                   │  J  ジャンプ
│ opcode │  rd  │  rs  │  rt  │       imm12           │  A  アトミック
│ opcode │                  0                         │  N
└────────┴──────┴──────┴──────┴───────────────────────┘
```

- `imm16`・`imm12` は符号付き (2 の補数) です。ただし `ANDI`・`ORI`・`XORI`・`LUI` の `imm16` は符号なし (0〜65535)、シフト量 (`SLLI` など) は 0〜31 です。
- `off16` は **PC+1 からの相対** (命令数) です。分岐先 = PC + 1 + off16。
- `target20` は**絶対**の命令番号 (0〜1048575) です。
- 使わないフィールドは 0 にします。復号するときは無視します。

例: `ADD r1, r2, r3` = `0x01123000`、`SW r6, 8(r7)` = `0x24670008`。

## 4. 命令

表の「動作」の記法: `M32[a]` は番地 a のワード、`M8[a]` はバイト、`sext` は符号拡張、`<ᵤ` は符号なし比較です。

### 4.1 基本整数命令 (I)

#### レジスタどうしの演算 (R 形式)

| 命令 | オペコード | 動作 |
|---|---|---|
| `ADD rd, rs, rt` | 0x01 | rd ← rs + rt |
| `SUB rd, rs, rt` | 0x02 | rd ← rs − rt |
| `AND rd, rs, rt` | 0x03 | rd ← rs & rt |
| `OR rd, rs, rt` | 0x04 | rd ← rs \| rt |
| `XOR rd, rs, rt` | 0x05 | rd ← rs ^ rt |
| `SLT rd, rs, rt` | 0x06 | rd ← (rs < rt) ? 1 : 0 (符号付き) |
| `SLTU rd, rs, rt` | 0x07 | rd ← (rs <ᵤ rt) ? 1 : 0 |
| `SLL rd, rs, rt` | 0x08 | rd ← rs << (rt & 31) |
| `SRL rd, rs, rt` | 0x09 | rd ← rs >>> (rt & 31) (論理) |
| `SRA rd, rs, rt` | 0x0A | rd ← rs >> (rt & 31) (算術) |

#### 即値との演算 (I 形式)

| 命令 | オペコード | 動作 |
|---|---|---|
| `ADDI rd, rs, imm` | 0x10 | rd ← rs + imm |
| `ANDI rd, rs, imm` | 0x11 | rd ← rs & imm (imm はゼロ拡張) |
| `ORI rd, rs, imm` | 0x12 | rd ← rs \| imm (ゼロ拡張) |
| `XORI rd, rs, imm` | 0x13 | rd ← rs ^ imm (ゼロ拡張) |
| `SLTI rd, rs, imm` | 0x14 | rd ← (rs < imm) ? 1 : 0 |
| `SLTIU rd, rs, imm` | 0x15 | rd ← (rs <ᵤ sext(imm)) ? 1 : 0 |
| `SLLI rd, rs, imm` | 0x16 | rd ← rs << imm |
| `SRLI rd, rs, imm` | 0x17 | rd ← rs >>> imm |
| `SRAI rd, rs, imm` | 0x18 | rd ← rs >> imm |
| `LUI rd, imm` | 0x19 | rd ← imm << 16 |

#### ロードとストア

| 命令 | 形式 | オペコード | 動作 |
|---|---|---|---|
| `LW rd, off(rs)` | I | 0x20 | rd ← M32[rs + off] |
| `LB rd, off(rs)` | I | 0x21 | rd ← sext(M8[rs + off]) |
| `LBU rd, off(rs)` | I | 0x22 | rd ← M8[rs + off] |
| `SW rt, off(rs)` | S | 0x24 | M32[rs + off] ← rt |
| `SB rt, off(rs)` | S | 0x25 | M8[rs + off] ← rt & 0xFF |

#### 分岐 (B 形式)

条件が成り立てば PC ← label、成り立たなければ PC ← PC + 1。

| 命令 | オペコード | 条件 |
|---|---|---|
| `BEQ rs, rt, label` | 0x28 | rs = rt |
| `BNE rs, rt, label` | 0x29 | rs ≠ rt |
| `BLT rs, rt, label` | 0x2A | rs < rt (符号付き) |
| `BGE rs, rt, label` | 0x2B | rs ≥ rt (符号付き) |
| `BLTU rs, rt, label` | 0x2C | rs <ᵤ rt |
| `BGEU rs, rt, label` | 0x2D | rs ≥ᵤ rt |

#### ジャンプとシステム

| 命令 | 形式 | オペコード | 動作 |
|---|---|---|---|
| `JAL rd, label` | J | 0x30 | rd ← PC + 1; PC ← label |
| `JALR rd, rs, imm` | I | 0x31 | t ← rs + imm; rd ← PC + 1; PC ← t |
| `HALT` | N | 0x3F | このコアを停止する |

`JALR` は rd と rs が同じレジスタでも、古い rs の値で飛び先を計算します。

### 4.2 乗算・除算 (M)

すべて R 形式です。

| 命令 | オペコード | 動作 |
|---|---|---|
| `MUL rd, rs, rt` | 0x40 | rd ← (rs × rt) の下位 32 ビット |
| `MULH rd, rs, rt` | 0x41 | rd ← (rs × rt) の上位 32 ビット (符号付き × 符号付き) |
| `MULHU rd, rs, rt` | 0x42 | rd ← (rs × rt) の上位 32 ビット (符号なし × 符号なし) |
| `DIV rd, rs, rt` | 0x44 | rd ← rs ÷ rt (符号付き、0 方向に切り捨て) |
| `DIVU rd, rs, rt` | 0x45 | rd ← rs ÷ rt (符号なし) |
| `REM rd, rs, rt` | 0x46 | rd ← rs − (rs ÷ rt) × rt (符号は rs と同じ) |
| `REMU rd, rs, rt` | 0x47 | 符号なしの剰余 |

0 による除算と桁あふれは例外にならず、次の値を返します (RISC-V と同じ)。

| 場合 | DIV | DIVU | REM | REMU |
|---|---|---|---|---|
| rt = 0 | −1 | 0xFFFFFFFF | rs | rs |
| rs = −2³¹, rt = −1 | −2³¹ | — | 0 | — |

### 4.3 アトミック (A)

すべてワード単位で、番地は 4 の倍数でなければなりません。

| 命令 | 形式 | オペコード | 動作 | 不可分 |
|---|---|---|---|---|
| `LL rd, off(rs)` | I | 0x50 | rd ← M32[a]; 予約 ← a | — |
| `SC rd, rt, off(rs)` | A | 0x51 | 予約 = a なら M32[a] ← rt, rd ← 1。そうでなければ rd ← 0。どちらでも予約を消す | ○ |
| `CAS rd, rt, off(rs)` | A | 0x52 | old ← M32[a]; old = rd なら M32[a] ← rt; rd ← old | ○ |
| `XCHG rd, off(rs)` | I | 0x53 | old ← M32[a]; M32[a] ← rd; rd ← old | ○ |
| `AMOADD rd, rt, off(rs)` | A | 0x54 | old ← M32[a]; M32[a] ← old + rt; rd ← old | ○ |

(a = rs + off)

**予約**: 各コアは予約を 1 つだけ持ちます (なし、または番地 1 つ)。`LL` で設定され、`SC` で消えます。また、**どのコアであれ**予約された番地のワードに書き込むと、そのワードを予約しているすべてのコアの予約が消えます (値が同じでも消えます)。

**不可分**: ○の命令は、読み出しから書き込みまでの間に他のコアの命令が入りません。

> CAS の成否は、返ってきた rd が期待値と等しいかで判断します。`SC` の rd は成功で 1 です (RISC-V の SC は成功で 0 なので逆です)。

### 4.4 独自拡張の例: Xmrmw

[docs/extending.md](extending.md) の見本として、ラボ用に用意した拡張です。

| 命令 | 形式 | オペコード | 動作 |
|---|---|---|---|
| `INCM off(rs)` | I | 0xC0 | M32[a] ← M32[a] + 1。2 つの μop (読み出し・書き込み) に分かれる |
| `LOCK INCM off(rs)` | I | 0xC0 | 同じ動作を 1 ステップで不可分に行う |

μop に分かれる命令は、1 ステップで 1 μop だけ進みます。μop の間に他のコアが動けます。`LOCK` 接頭辞を付けた命令は、すべての μop を 1 ステップで行います。`LOCK` は機械語には現れず、アセンブラとシミュレータが扱う印です (版 1.0)。

## 5. 疑似命令

アセンブラが本物の命令に置き換えるものです。CPU から見ると存在しません。

| 疑似命令 | 置き換え先 |
|---|---|
| `NOP` | `ADDI r0, r0, 0` |
| `LI rd, imm` | −32768〜32767 なら `ADDI rd, r0, imm`。32768〜65535 なら `ORI rd, r0, imm`。それ以外は `LUI rd, 上位16ビット` (+ 下位が 0 でなければ `ORI rd, rd, 下位16ビット`) |
| `LA rd, label` | `LI` と同じ (番地を読み込む) |
| `MOV rd, rs` | `ADDI rd, rs, 0` |
| `NEG rd, rs` | `SUB rd, r0, rs` |
| `SUBI rd, rs, imm` | `ADDI rd, rs, −imm` |
| `BEQZ rs, label` / `BNEZ rs, label` | `BEQ rs, r0, label` / `BNE rs, r0, label` |
| `BGT rs, rt, label` / `BLE rs, rt, label` | `BLT rt, rs, label` / `BGE rt, rs, label` |
| `BGTU` / `BLEU` | `BLTU` / `BGEU` (オペランドを入れ替える) |
| `J label` | `JAL r0, label` |
| `JR rs` | `JALR r0, rs, 0` |
| `CALL label` | `JAL r15, label` |
| `RET` | `JALR r0, r15, 0` |

`LI` は値によって 1 命令にも 2 命令にもなります。ラベルの位置は置き換えた後の命令数で決まります。

## 6. 例外

次のとき、コアは止まり、例外の理由を記録します。

| 原因 | 例 | 止まったときの状態 |
|---|---|---|
| データメモリの範囲外 | `LW r1, 0x10000(r0)` (メモリが 64 KiB のとき) | その命令は実行されていない (レジスタもメモリも変わらない) |
| ワード番地が 4 の倍数でない | `LW r1, 2(r0)` | 同上 |
| PC がプログラムの外 | `JR` で存在しない番号へ飛んだ | ジャンプ命令は実行済み (rd は書かれている)。次の命令を取り込めずに止まる |

割り込み・特権モード・仮想記憶はありません (版 1.0)。

## 7. 停止

コアは次のどちらかで止まります。

- `HALT` を実行した
- 最後の命令の次 (PC = 命令数) に進んだ。プログラムの末尾に `HALT` を書かなくてもよいのはこのためです

すべてのコアが止まると、マシン全体が止まります。

## 8. 版について

この仕様の版は「主版.副版」です。既存のプログラムの意味が変わる変更は主版を上げ、命令や拡張を足すだけの変更は副版を上げます。シミュレータ (`core/`) の変更は、この文書の変更と同時に行います。
