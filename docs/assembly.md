# TOY アセンブリ言語

版: 1.0 — 実装: `core/assembler.js`

## 1. 行の形

1 行に書けるのは次のものです。どれも省略できます。

```
ラベル:  命令または疑似命令  オペランド, オペランド, …   ; コメント
```

```asm
loop:   LW   r2, 0(r1)      ; A[i] を読む
        ADD  r10, r10, r2   # これもコメント
done:                       ; ラベルだけの行
```

- **コメント**は `;` または `#` から行末まで。文字定数 `'#'` の中は除きます。
- **ラベル**は英字・`_`・`.`・`$` で始まり、英数字・`_`・`.`・`$` が続く名前に `:` を付けます。1 行に複数書けます。`r0`〜`r15` はラベルにできません。
- **大文字と小文字**: 命令名・レジスタ名・疑似命令名は区別しません (`add`, `ADD`, `R1`, `r1`)。ラベルと `.equ` の名前は区別します。
- 空白とタブの量は自由です。

## 2. オペランド

| 種類 | 書き方 | 例 |
|---|---|---|
| レジスタ | `r0`〜`r15` | `r7` |
| 数・式 | §3 を参照 | `42`, `0x100`, `N*4`, `buf+8` |
| メモリ | `式(レジスタ)`、`(レジスタ)`、`式` | `8(r1)`, `(r1)`, `counter`, `buf+4(r2)` |
| ラベル (飛び先) | 式 | `loop` |

メモリオペランドで `(レジスタ)` を省くと `r0` を基準にした絶対番地になります。`LW r1, counter` は `LW r1, counter(r0)` と同じです。

オペランドの数と種類は命令ごとに決まっています ([命令セット仕様](isa.md) §4)。違っていれば、正しい形を添えてエラーになります。

## 3. 数と式

| 書き方 | 意味 |
|---|---|
| `123`, `-5` | 10 進数 |
| `0x7F` | 16 進数 |
| `0b1010` | 2 進数 |
| `'A'`, `'\n'` | 文字コード (`\n` `\t` `\0` が使える) |
| ラベル名 / `.equ` の名前 | その値 |

これらを `+`、`-`、`*`、括弧 `( )` でつないだ式が書けます。`*` は `+` `-` より先に計算します。

ラベルの値は、`.text` では**命令の番号**、`.data` では**バイト番地**です。

値が命令の即値の範囲に入らないとエラーになります。範囲は[命令セット一覧](../reference/)の「即値の範囲」にあります。16 ビットに収まらない定数は `LI` で読み込みます。

## 4. セクション

プログラムは 2 つのセクションに分かれます。

- `.text` — 命令を書く場所 (最初はここ)
- `.data` — データメモリの初期値を書く場所

`.data` の後でも `.text` と書けば命令に戻れます。何度切り替えてもかまいません。`.data` に命令を書くとエラーです。

## 5. アセンブラ指令

| 指令 | 使える場所 | 意味 |
|---|---|---|
| `.text` / `.data` | どこでも | セクションを切り替える |
| `.org 番地` | `.data` | 次のデータを置く番地を決める |
| `.align n` | `.data` | 番地を n の倍数に進める (n は 2 のべき乗) |
| `.word 式, 式, …` | `.data` | 4 バイトずつ置く。番地は 4 の倍数であること |
| `.byte 式, 式, …` | `.data` | 1 バイトずつ置く (−128〜255) |
| `.space n [, 埋める値]` | `.data` | n バイト空ける (既定は 0 で埋める) |
| `.equ 名前, 式` | どこでも | 名前に値を付ける。前方参照・入れ子の参照ができる |
| `.region 名前` / `.endregion` | どこでも | 間にある命令に名前を付ける (§7) |

`.data` の最初の番地は 0 です (アセンブラの `dataBase` で変えられます)。

```asm
        LA   r1, table
        LW   r2, 4(r1)       ; 20
        HALT

.data
.org 0x100
table:  .word 10, 20, 30
msg:    .byte 'O', 'K', 0
.align 4
buf:    .space 64
```

## 6. 疑似命令と接頭辞

疑似命令 (`LI`, `MOV`, `J`, `CALL` など) は 1〜2 個の本物の命令に置き換わります。一覧は[命令セット仕様](isa.md) §5 です。置き換えた命令は、元の行番号と元の書き方 (`src`) を覚えています。

接頭辞は命令の前に書く語で、許された命令にだけ付けられます。版 1.0 では Xmrmw 拡張の `LOCK` だけがあります (`LOCK INCM counter`)。

## 7. 領域 (`.region`)

`.region 名前` から `.endregion` までの命令には、その名前が付きます (入れ子にでき、内側の命令は両方の名前を持ちます)。命令の意味は変わりません。ラボが「この範囲はクリティカルセクション」のように印として使います。

## 8. 呼び出し側が与える記号

ラボは、アセンブルするときに記号をあらかじめ与えられます (`assemble(src, { isa, symbols: { counter: 0, lock: 4 } })`)。プログラムの中から同じ名前を `.equ` で定義し直すとエラーになります。

## 9. エラー

アセンブラはエラーを見つけても止まらず、全部の行を調べてから、行番号つきのエラーをすべて返します。エラーが 1 つでもあれば、プログラムは作られません。

| よくあるエラー | 例 |
|---|---|
| 未知の命令 | `命令「FOO」は TOY-IMA にありません` |
| オペランドの数 | `ADD のオペランドは 3 個です (ADD rd, rs, rt)` |
| レジスタ名 | `レジスタ「r16」は r0〜r15 で書きます` |
| 即値の範囲 | `ADDI の即値 70000 は -32768〜32767 の範囲で書きます。大きな定数は LI で読み込みます。` |
| ラベル | `ラベル「loop」が見つかりません`、`二重に定義されています` |
| データの配置 | `.word は4の倍数の番地に置きます (いまは 5。前に .align 4 を)` |

## 10. 出力

アセンブルの結果 (`program`) には次のものが入っています。詳しくは [API リファレンス](api.md)。

- `instrs` — 命令の配列 (番号・機械語・正規化した表記・元の行・元の書き方)
- `labels` — 記号表
- `data` — データメモリの初期値
- `lines` — ソースの各行と、その行から生まれた命令の番号
