# 用語集

ラボの画面・ドキュメント・コードのコメントで使う言葉をここで決めます。新しいラボや教材を作るときも、この表に合わせてください。`tests/terms.test.js` が、使わないことにした言葉が紛れ込んでいないかを確かめます。

## 全体の呼び名

| 使う言葉 | 意味 | 使わない言葉 |
|---|---|---|
| 仮想CPU ラボ | このサイトとリポジトリ全体の名前 | 実験室 (全体の名前として) |
| TOY | この仮想 CPU と命令セットの名前 | |
| ラボ | 1 つの学習用ページ。名前は「〇〇・ラボ」 | 教室、実験室、実験台、アプリ |
| ドキュメント | `docs/` にある文書の集まり。1 本ずつは「この文書」「命令セット仕様」のように呼ぶ | 仕様書 (集まりの名前として) |
| シミュレータ本体 | `core/` の中身 (命令セット・アセンブラ・Machine・タイミングモデル) | 共通コア (CPU のコアと紛らわしいため) |
| 構成 | ラボで使う CPU の設定の組み合わせ。名前の付いたものは「基準構成」(TOY-5・CL-1・LT-1・AL-2) | 仮想CPU (構成の名前として) |

## ラボの名前

| ラボ | フォルダ | 構成 |
|---|---|---|
| 命令セット・ラボ | `labs/playground/` | (既定の Machine) |
| パイプライン・ラボ | `labs/pipeline/` | TOY-5 |
| スループット・ラボ | `labs/throughput/` | TOY-5 |
| キャッシュ・ラボ | `labs/cache/` | CL-1 |
| レイテンシ・ラボ | `labs/latency/` | LT-1 |
| アトミック・ラボ | `labs/atomic/` | AL-2 |

## 教材の単位

| 使う言葉 | 意味 | 使わない言葉 |
|---|---|---|
| 単元 | [学習カリキュラム](curriculum.md) の区切り。1 つの単元で 1〜2 個のラボを使う | 章、回 |
| レッスン | ラボの中の学習の区切り。説明・「試してみよう」・ポイントを持つ (レイテンシ・ラボ、アトミック・ラボ) | |
| プログラム | ラボで選んで動かすコード。レッスンの中の選択肢もプログラムと呼ぶ | 実験、サンプル、バリアント、例題、プリセット |
| 課題 | 条件を満たすと達成になる目標 (スループット・ラボ) | チャレンジ |
| 確認問題 | 単元の終わりに解く問題 | |
| 教材 | 上のものの総称。コードでは各ラボの `lessons.js` | |

## 技術用語

| 使う言葉 | 意味 | 使わない言葉 |
|---|---|---|
| 番地 | データメモリの位置 (バイト単位) | アドレス |
| 命令番号 | 命令メモリの位置。PC の値 | 命令アドレス |
| ワード | 4 バイト | 語 (説明文では「16語」のように数えるときだけ使ってよい) |
| ライン | キャッシュがまとめて運ぶ単位。大きさは「ライン長」 | ブロック |
| サイクル | クロック 1 回分の時間 | クロック (時間の単位として) |
| ステップ | Machine が 1 命令 (μop 命令なら 1 μop) を進める単位 | |
| ストール | パイプラインで命令が先へ進めずに待つこと。画面では「待ち」とも書く | |
| 取り消し | 誤って取り込んだ命令を捨てること (フラッシュ) | |
| 分岐予測ミス | 分岐予測が外れること。表の中など短く書くときは「予測ミス」 | |
| 不可分 | 他のコアに割り込まれずに一度に行われること (アトミック) | |
| 実行記録 / トレース | Machine が 1 ステップごとに出す記録 / その列 | ログ (この意味では) |
| 例外 | 番地の範囲外などでコアが止まること | トラップ (画面の文言では) |

## 表記の約束

- ラボの名前は「〇〇・ラボ」と中黒で区切る。
- 数と単位の間は半角空白 (「64 B」「200 サイクル」) を基本とし、画面の狭い場所では詰めてよい。
- 命令名・レジスタ名はコードとして書く (`ADD`、`r1`)。
