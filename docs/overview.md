# はじめに

**仮想CPU ラボ**は、小さな仮想 CPU「TOY」を動かしながらコンピュータアーキテクチャを学ぶための教材と、その土台になるシミュレータのセットです。

- 学ぶ人は、ブラウザで[ラボ](../)を開くだけで、パイプライン・キャッシュ・記憶階層・マルチコアの動きを 1 サイクル・1 命令ずつ確かめられます。
- 教える人や作る人は、命令・CPU の構成・教材を足して、自分の授業や研究に合わせたラボを作れます。

## 3 つの層

```
┌───────────────────────────────────────────────────────────────┐
│ ラボ (labs/)                                                    │
│  パイプライン・ラボ ・ スループット・ラボ ・ キャッシュ・ラボ          │
│  レイテンシ・ラボ ・ アトミック・ラボ ・ 命令セット・ラボ                  │
├───────────────────────────────────────────────────────────────┤
│ タイミングモデル (core/)  「いつ起きるか」                          │
│  5段パイプライン ・ インオーダー発行 ・ キャッシュ ・ メモリ階層 ・ 分岐予測 │
├───────────────────────────────────────────────────────────────┤
│ 命令セットと機能シミュレータ (core/)  「何が起きるか」               │
│  TOY 命令セット (I・M・A + 独自拡張) ・ アセンブラ ・ Machine         │
└───────────────────────────────────────────────────────────────┘
```

すべてのラボは同じ命令セットと同じシミュレータを使います。あるラボで書いたプログラムは、別のラボでもそのまま動きます。
